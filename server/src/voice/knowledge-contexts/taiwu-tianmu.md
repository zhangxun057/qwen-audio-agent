# 《太吾绘卷：天幕心帷》近期更新知识包

资料快照日期：2026-08-17。游戏正式名称是《太吾绘卷》，完全版名称是《太吾绘卷：天幕心帷》。“太古绘卷”“天目新维”“天幕新维”在本实验中视为语音识别近音词。

资料依据为 Steam 上《太吾绘卷》官方活动与公告页公开的 2026 年 7 月更新说明。

## 2026-07-22 UI 交互优化

- 周天运转界面新增功法状态筛选：“已周天”和“未周天”，用来区分内力增长已经完成或尚未完成的功法。
- 周天运转界面新增“五行转移”筛选，可按转移目标属性筛选。
- 辅运内功增加它能提供的“周天策略”及子类筛选，同时增加品级排序。
- 研读书籍界面增加研读策略及子类筛选，并可按书籍已研读百分比排序；所有书页研读进度合计为 100%。
- 世界地图增加地区、标识、状态三类筛选。

## 制造与精益求精

- 产业制造界面默认展示“选择引子”和“选择工具”列表，产物类型独立展示。
- 制造次数增加一键最大和一键最小快捷按钮。
- “精益求精”现在默认为无词条，玩家可以选择指定词条或随机词条来触发。
- 制造武具时增加武具材质特殊词条的效果预览。
- 指定产物使用独立选择弹窗，每个产物直接显示所需引子与工具。

## 2026-07-24 补丁补充

- 优化“使用秘闻”界面排序页签排版。
- 优化放入蛟池界面的确认快捷键。
- 调整小黑蛇改换书页界面中正逆心法的位置，使其与人物突破界面一致。
- 修复少林派地区升级剧情中，跳过首个过月事件可能报错的问题。
